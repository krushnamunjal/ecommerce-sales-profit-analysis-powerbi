# E-Commerce Sales & Profit Analysis | Power BI

This project is a Power BI dashboard created to analyze e-commerce sales and profit data.

### What I analyzed

* Total sales, profit and quantity
* Monthly profit performance
* Sales by state
* Category and sub-category performance
* Customer-wise sales
* Payment mode distribution

### Tools

* Power BI
* Power Query
* DAX

### Dashboard

The dashboard includes interactive quarterly filters, KPI cards, and charts for sales and profit analysis.
